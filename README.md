# LogistikPro PWA

**LogistikPro PWA** adalah aplikasi web modern berbasis Progressive Web App (PWA) yang dirancang khusus untuk mengelola operasional logistik, manajemen armada (trips), pencatatan pengiriman material, pembuatan invoice, dan rekapitulasi data perjalanan secara efisien.

## 🎯 Untuk Apa Aplikasi Ini?
Aplikasi ini dibuat untuk menyederhanakan dan mengotomatisasi proses bisnis di bidang logistik dan transportasi darat, khususnya dalam hal:
- Pencatatan ritase (trip) perjalanan armada harian secara *real-time*.
- Manajemen data *Master* seperti data Kendaraan, Pemilik (Owner) armada, Proyek, dan Kuari/Lokasi.
- Perhitungan kubikasi (volume) material dan nominal harga secara otomatis.
- Pembuatan, pengelolaan, dan pencetakan Invoice serta Slip pembayaran secara presisi.
- Manajemen kasbon, potongan, dan analisis margin/keuangan operasional.

## 👥 Siapa Pengguna Aplikasi Ini?
Sistem ini sangat cocok dan dirancang untuk digunakan oleh:
1. **Perusahaan Logistik / Vendor Transportasi**: Untuk melacak pengiriman material, ritase, dan performa setiap unit armada.
2. **Staf Administrasi & Keuangan**: Mempermudah pembuatan tagihan (invoice) harian maupun borongan, mencetak slip pembayaran, serta melacak mutasi kasbon dan potongan secara akurat.
3. **Pemilik Armada (Owner)**: Untuk mendapatkan rekap hasil perjalanan (trip) yang transparan dan akurat.
4. **Manajer Proyek (Project Manager)**: Untuk mengontrol alokasi masuknya material ke lokasi proyek beserta rincian anggarannya.

## ✨ Kelebihan Utama
- **Cepat dan Responsif**: Dibangun menggunakan ekosistem web modern (React, TypeScript, Vite) sehingga aplikasi terasa sangat ringan dan cepat.
- **Dukungan Offline (PWA & Local DB)**: Menggunakan teknologi Progressive Web App dan basis data lokal (IndexedDB via Dexie.js), memungkinkan pengguna tetap bisa mengakses dan menyimpan data meskipun koneksi internet sedang tidak stabil atau *offline*.
- **Desain UI/UX Modern & Intuitif**: Antarmuka pengguna yang bersih, profesional, dan mudah dinavigasi (menggunakan Tailwind CSS & Radix UI).
- **Cetak Laporan yang Akurat**: Fitur cetak laporan (Slip, Invoice, Rekap) terintegrasi langsung di dalam aplikasi dengan presisi desimal yang tinggi, siap cetak ke PDF maupun printer fisik.
- **Cross-Platform**: Sebagai PWA, aplikasi ini dapat diakses melalui browser apapun dan bisa "di-install" langsung ke layar utama (*homescreen*) *smartphone*, tablet, maupun desktop tanpa perlu mengunduh dari App Store/Play Store.
